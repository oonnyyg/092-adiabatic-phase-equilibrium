# phase_balance — 绝热相平衡计算工具

仅用 Python 标准库实现的绝热混合计算工具：多种互不溶解的材料在绝热
容器中只交换热量（忽略反应、蒸发与容器吸热），求出共同平衡温度、
各材料液相比例，并核对吸放热闭合。

## 运行

```sh
python -m phase_balance 输入.json --out 输出目录
```

输出：

- `材料结果CSV`：`<输出目录>/materials.csv`，每行一种材料的末温、
  末态液相比例、初/末焓与净吸热（J）。
- `汇总JSON`：`<输出目录>/summary.json`，每个实验的末温、总初焓、
  总末焓与焓残差，以及各材料明细。

示例输入见 `examples/input.json`。

## 单位与量纲

统一使用 kg、J、°C：

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `mass_kg` | 质量（>0） | kg |
| `cp_solid` / `cp_liquid` | 固/液比热（>0） | J/(kg·°C) |
| `melting_point_c` | 熔点 | °C |
| `latent_heat` | 单位质量熔化潜热（>0） | J/kg |
| `initial_temp_c` | 初温 | °C |
| `initial_liquid_fraction` | 初始液相比例，仅初温恰等于熔点时必填 | 0–1 |

所有数值必须有限；质量、比热、潜热必须为正；同一实验内各材料编号
唯一、熔点互不相同；每个实验至少一种材料。任一实验非法则整批失败，
不生成任何报告。

## 焓模型

以各材料熔点处的全固态为零焓，单位质量焓为：

- `T < Tm`：`cp_solid * (T - Tm)`（负值）
- `T = Tm`：`latent_heat * 液相比例`
- `T > Tm`：`latent_heat + cp_liquid * (T - Tm)`

总焓再乘质量。初温低于熔点视为全固，高于熔点视为全液，恰等于熔点
必须给出 0–1 的初始液相比例；其他温度不允许指定比例。

## 平衡求解与相变边界

总初焓守恒。系统焓随温度分段线性、单调递增，在每个熔点处有一段
潜热平台（温度停在熔点、液相比例从 0 连续变化到 1）：

- 若总焓落在某材料的潜热区间内，平衡温度即为该熔点，按比例
  反解该材料的部分液化比例（0–1），其余材料按末温判定全固或全液。
- 否则总焓落在两个熔点之间的显热段，温度在该段内线性求解，
  不跨过相变区直接平均温度。

由于同一实验内熔点互不相同，任一时刻至多一种材料处于相变平台，
解唯一。

## 精度与闭合

每个实验报告总初焓、总末焓、焓残差（`enthalpy_residual_j`）以及
各材料净吸热（`net_heat_j`，吸热为正）；所有材料净吸热之和即为
残差，应在浮点误差范围内闭合（温度绝对误差 ≤ 1e-7 °C，液相比
误差 ≤ 1e-8）。
